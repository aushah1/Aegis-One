The [MIT license](LICENSE) covers the Aegis One team's own code and docs. These files keep
their own licenses; see [docs/DATA.md](docs/DATA.md) for sources:

- shared/atlas.json: built from DuckDuckGo Tracker Radar, CC BY-NC-SA 4.0
  (non-commercial, share-alike). Commercial use of Aegis One needs a different
  tracker source or a license from DuckDuckGo.

- shared/cookie-db.json: built from the Open Cookie Database, Apache 2.0.
- shared/state-media.json: facts from State Media Monitor (MJRC), which
  states no license; credited as the source.
- California Data Broker Registry: public records from the California
  Privacy Protection Agency.
- vendor/litert-lm/ (in-browser version): Google LiteRT-LM, Apache 2.0.
- Gemma 4 model weights (downloaded by the user, not in this repo): Apache 2.0.
